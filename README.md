Eject is a plugin for Euro Truck Simulator 2 and American Truck Simulator, written in C++20. It runs directly inside the game through the official SCS plugin interface (SCS SDK) and ships as a single DLL. There is no separate application.

Eject is meant to bring a range of features to the game. One of them is a realistic autopilot that drives more like a careful human driver. Other features will include things like graphics enhancements and truck repairs, with more added over time. The autopilot will be free to use, while some other features will be paid and unlocked with a license key.

| Status | Platforms |
| --- | --- |
| Eject is at a very early stage. I'm building it from the ground up, and there is nothing to download or try yet. | Windows is the initial target. Linux and macOS support is planned. |
